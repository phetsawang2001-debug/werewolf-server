# คืนหมาป่า (เกมหมาป่าออนไลน์)

เล่นกับเพื่อน 4-16 คนผ่านลิงก์ ไม่ต้องล็อกอิน เซิร์ฟเวอร์เป็นคนเก็บบทบาท ส่งให้แต่ละคนเฉพาะของตัวเอง

## วิธีรันบนคอมของคุณ

1. ติดตั้ง Node.js เวอร์ชัน 18 ขึ้นไป จาก https://nodejs.org (เลือก LTS)
2. แตกไฟล์ zip แล้วเปิด Terminal (Windows: PowerShell) เข้าไปในโฟลเดอร์ werewolf-server
3. รัน (ครั้งแรกเท่านั้น):  `npm install`
4. รันเกม:  `npm start`
   จะขึ้นข้อความ "คืนหมาป่า รันอยู่ที่ http://localhost:3000"

เปิด http://localhost:3000 บนคอมเครื่องเดียวกันเพื่อลองเล่นได้เลย

## ให้เพื่อนที่อยู่คนละที่เข้ามาเล่น (ลิงก์ชั่วคราว)

ใช้ Cloudflare Tunnel (ฟรี ไม่ต้องสมัคร):

1. ติดตั้ง cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
   - macOS:  `brew install cloudflared`
   - Windows:  `winget install --id Cloudflare.cloudflared`
2. เปิดเกมไว้ใน Terminal หน้าต่างแรก (`npm start`)
3. เปิด Terminal หน้าต่างที่สอง แล้วรัน:  `cloudflared tunnel --url http://localhost:3000`
4. มันจะพิมพ์ลิงก์ลักษณะ `https://xxxx-xxxx.trycloudflare.com` ออกมา
5. เปิดลิงก์นั้นเอง กด "สร้างห้องใหม่" แล้วกด "คัดลอกลิงก์ชวนเพื่อน" ส่งให้เพื่อน

ข้อควรรู้
- คอมต้องเปิดและรัน 2 หน้าต่างนี้ค้างไว้ตลอดเวลาที่เล่น
- ลิงก์ trycloudflare เปลี่ยนทุกครั้งที่รัน tunnel ใหม่
- ถ้าเล่นในวง Wi-Fi เดียวกัน ไม่ต้องใช้ tunnel ให้เพื่อนเปิด http://IP-ของคอมคุณ:3000 แทน
- ห้องเก็บในหน่วยความจำ ถ้าปิดเซิร์ฟเวอร์ ห้องหายทั้งหมด

## กติกาย่อ
- กลางคืน: หมาป่าเลือกเหยื่อ ผู้หยั่งรู้เลือกส่อง หมอเลือกปกป้อง
- กลางวัน: ทุกคนคุยกัน (ใช้โทรหรือไลน์ข้างนอก) โฮสต์กดเริ่มโหวต
- โหวตประหาร คะแนนเสมอคือไม่มีใครตาย
- ชาวบ้านชนะเมื่อหมาป่าหมด หมาป่าชนะเมื่อจำนวนเท่ากับหรือมากกว่าคนอื่น
