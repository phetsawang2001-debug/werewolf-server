# คืนหมาป่า (เกมหมาป่าออนไลน์)

เล่นกับเพื่อน 4-16 คนผ่านลิงก์ ไม่ต้องล็อกอิน เซิร์ฟเวอร์เป็นคนเก็บบทบาท ส่งให้แต่ละคนเฉพาะของตัวเอง

## บทบาท
| บทบาท | ความสามารถ |
|---|---|
| ชาวบ้าน | ไม่มีความสามารถพิเศษ ใช้การสังเกตและคุยกันหาตัวหมาป่า |
| หมาป่า | ทุกคืนเลือกเหยื่อ คุยกับเพื่อนหมาป่าในแชทหมาป่าได้ตอนกลางคืน |
| หมอดู | ทุกคืนส่องหนึ่งคน เช้ามารู้ว่าเป็นหมาป่าหรือไม่ |
| แม่มด | เห็นเหยื่อของหมาป่าก่อนตัดสินใจ มียาช่วย 1 ขวดกับยาฆ่า 1 ขวด ใช้ได้ครั้งเดียวต่อขวด และคืนหนึ่งใช้ได้ขวดเดียว |

จำนวนผู้เล่น 4 คน = หมาป่า 1 + ชาวบ้าน 3 · 5 คน เพิ่มหมอดู · 6 คนขึ้นไป เพิ่มแม่มด · 8 คนขึ้นไป หมาป่า 2 · 12 คนขึ้นไป หมาป่า 3

## แชท
- ห้องรอและหลังจบเกม: คุยกับทุกคน
- กลางวันและตอนโหวต: คนที่ยังมีชีวิตคุยกันได้ทุกคน
- กลางคืน: ปิดแชทสำหรับทุกคน ยกเว้นหมาป่าที่คุยกันเองได้ในช่องลับ
- คนที่ตายแล้วและผู้ชมคุยกันได้ในช่องคนตาย คนที่ยังเล่นอยู่มองไม่เห็น
- พอจบเกม ทุกช่องจะเปิดให้ทุกคนเห็น

## วิธีรันบนคอมของคุณ
1. ติดตั้ง Node.js เวอร์ชัน 18 ขึ้นไป จาก https://nodejs.org (เลือก LTS)
2. แตกไฟล์ zip แล้วเปิด Terminal (Windows: PowerShell) เข้าไปในโฟลเดอร์ werewolf-server
3. รัน (ครั้งแรกเท่านั้น):  `npm install`
4. รันเกม:  `npm start`  จะขึ้นข้อความ "คืนหมาป่า รันอยู่ที่ http://localhost:3000"

เปิด http://localhost:3000 บนคอมเครื่องเดียวกันเพื่อลองเล่นได้เลย

## ให้เพื่อนที่อยู่ไกลเข้ามาเล่น

### ทางที่ 1: ลิงก์ชั่วคราวจากคอมของคุณ (Cloudflare Tunnel, ฟรี ไม่ต้องสมัคร)
1. ติดตั้ง cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
   - macOS:  `brew install cloudflared`
   - Windows:  `winget install --id Cloudflare.cloudflared`
2. เปิดเกมไว้ในหน้าต่างแรก (`npm start`)
3. เปิดหน้าต่างที่สอง แล้วรัน:  `cloudflared tunnel --url http://localhost:3000`
4. จะได้ลิงก์ลักษณะ `https://xxxx-xxxx.trycloudflare.com` เปิดลิงก์นั้นเอง กด "สร้างห้องใหม่" แล้วกด "คัดลอกลิงก์ชวนเพื่อน"

คอมต้องเปิดและรัน 2 หน้าต่างนี้ค้างไว้ตลอดที่เล่น ลิงก์เปลี่ยนทุกครั้งที่เปิด tunnel ใหม่
ถ้าเล่นในวง Wi-Fi เดียวกัน ให้เพื่อนเปิด http://IP-ของคอมคุณ:3000 แทนได้เลย

### ทางที่ 2: โฮสต์ฟรีบน Render (ได้ลิงก์ถาวร)
1. สร้าง repository บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นไป (ไม่ต้องอัปโหลดโฟลเดอร์ node_modules)
2. สมัคร https://render.com เลือก New → Web Service เชื่อมกับ repository นั้น
3. Build Command: `npm install`   Start Command: `npm start`   แผน: Free
4. กด Deploy รอจนได้ลิงก์ `https://ชื่อ.onrender.com`

ข้อควรรู้ของแผนฟรี: ถ้าไม่มีใครใช้ 15 นาที เซิร์ฟเวอร์จะหลับ เปิดครั้งแรกอาจรอประมาณ 1 นาที

## ข้อจำกัด
- ห้องเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ทหรือหลับ ห้องจะหายทั้งหมด
- ผู้เล่นที่หลุดกลับเข้ามาเล่นต่อได้ ถ้าเปิดลิงก์เดิมด้วยเบราว์เซอร์เดิม
